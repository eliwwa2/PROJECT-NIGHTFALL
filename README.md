
# PROJECT NIGHTFALL

## Über das Spiel
PROJECT NIGHTFALL ist ein realistisches 3D-Psychological-Horror-Spiel für iOS.

## Spielperspektive
First Person

## Hauptgegner
THE STALKER

## Funktionen
- Realistische Monster-KI
- Monster hört Geräusche
- Dynamische Jumpscares
- Verstecksystem
- Lebens- und Todessystem
- Dunkle Krankenhausumgebung
- Mobile Steuerung
